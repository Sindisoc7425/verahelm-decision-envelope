# Privacy boundary

Allowed inputs are identifiers, bounded scope text, immutable digests, timestamps, declared conditions, and public verification keys.

Never place raw evidence, source code, prompts, model output, traces, logs, datasets, credentials, personal data, customer records, repository contents, internal URLs, or confidential strategy in a Decision Envelope or repository contribution.

The verifier is offline and contains no telemetry. GitHub and other hosting platforms have their own data practices; review them before publication or use.
