# Contributing

Issues and pull requests may address public schemas, verifier correctness, fictional conformance fixtures, accessibility, or documentation.

Before submitting:

1. use fictional data only;
2. run `npm test`;
3. explain compatibility impact;
4. include no private method, production detail, customer material, credential, or reverse-engineering aid.

Contributions are offered for inclusion under this repository’s license. Do not contribute material you cannot license. Maintainers may decline changes that expand the disclosure boundary.
